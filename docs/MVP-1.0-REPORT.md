# Teyvat Tasks MVP 1.0 — отчёт о проверке

Дата: 2026-10-19. Версия приложения: 1.0.0. Версия JSON-схемы: 1.

Этот отчёт фиксирует локальную проверку перед выпуском. На момент её завершения публикация, удалённый workflow и `git push` не выполнялись. Последующее согласование и результаты публикации записываются в [HISTORY.md](HISTORY.md).

## Что готово

- Семь работающих разделов, адаптация и две темы. Сервер выбирается в настройках и рутине; настройка сохраняется и не удаляет историю других серверов.
- Рутина с ручными шаблонами, счётчиками, отменой, неизменяемыми при сбросе периодами и фиксированными серверными смещениями.
- Приблизительная смола с UTC-замерами, восстановлением, расходом, коррекцией и защитой от повторного начисления.
- Ручные персонажи, материалы, расписания и планы фарма; отметка плана не меняет инвентарь.
- Личные задачи и категории, фильтры, UTC-время выполнения, возврат в работу.
- Производная статистика без дублирующих счётчиков и без выдуманных пропусков/дат старых отметок.
- Экспорт всего рабочего документа, строгая проверка импорта, предпросмотр количества записей, обязательное подтверждение и резервная копия до замены.
- Подтверждаемая очистка рабочих данных с резервной копией. Копия скачивается и восстанавливается обычным импортом. Для повреждённой записи доступно скачивание исходного текста.
- Обнаруженное устаревшее состояние вкладки блокирует обычную запись; изменения после предпросмотра блокируют замену. Ошибки доступа и квоты не выдаются за успешное сохранение.
- Версия и документация обновлены. Workflow GitHub Pages стал ручным, запускает тесты и готовит ограниченный артефакт приложения.

## Браузерная проверка

Сценарии выполнены headless Chromium через доступный в среде Playwright; в зависимости приложения библиотеки не добавлены.

- Повторно пройдены браузерные сценарии рутины, смолы, персонажей/фарма и личных задач/статистики. Включены управляемые часы и переход через настоящий для страницы момент сброса/восстановления, а не только наличие DOM-элементов.
- Проверены настройки сервера и темы после обновления страницы, открытия новой вкладки, полного закрытия и повторного запуска Chromium с тем же профилем.
- Скачанный экспорт прочитан как JSON и сравнен с текущими данными. Проверены скачивание копии, очистка и восстановление всех записей из скачанного файла.
- В интерфейсе отклонены повреждённый JSON, чужая schemaVersion, неверный тип, ID, дубликат, оборванная ссылка и файл больше 5 МиБ. Содержимое рабочего ключа не изменилось, новая копия от неверного файла не появилась.
- Предпросмотр не заменяет данные. Проверены отмена, обязательный флажок, подтверждение клавиатурой, инвалидирование предпросмотра после смены настроек и отказ при изменении хранилища другой вкладкой.
- Проверены запрет доступа, ошибка создания копии и ошибка записи после копирования. Рабочий JSON сохранился; во втором случае копия осталась доступна. Повреждённый исходный текст скачан до восстановления и из копии после него.
- Проверены повторный выбор того же файла после отмены, отсутствие возврата отменённого асинхронного предпросмотра и дополнительная проверка подтверждающей формы.
- Все семь экранов проверены на 320, 360, 390, 768 и 1440 px, включая таблицу предпросмотра на 320 px. Исправлено переполнение карточки цели длинным непрерывным текстом.
- Проверены клавиатурные Enter/Space/Tab, ссылка перехода к содержимому, меню и Escape, тема, сервер и импорт. У полей есть подписи, у кнопок — имена, ошибки используют role=alert и фокус, успешные операции — role=status. Усилена контрастность вторичного текста светлой темы.
- Импортированы проверяемые строки с HTML в именах, задачах, шаблонах, материалах, заметках и имени файла. На экранах не появились пользовательские img/onerror/onload-элементы, код из строк не исполнился. Ошибок JavaScript и запросов к внешним сервисам в сценариях не обнаружено.
- Просмотрены снимки экрана компьютера и телефона.

## Подготовка публикации

Локально собран тот же состав, который готовит workflow: `index.html`, `src/`, `.nojekyll`. Старая страница, видео, тесты и пользовательские JSON не включены.

Артефакт запущен из подпапки `/teyvat-tasks/`: открыты все семь экранов, загружены относительные CSS и ES Modules. Ошибок загрузки и отсутствующих файлов не обнаружено. Это локальная проверка состава и путей, не публикация GitHub Pages.

Инструкция запуска, резервного копирования, импорта, очистки и ручной публикации находится в [README](../README.md). Все ссылки на файлы относительные.

## Что не проверено

- На этапе локальной проверки не проверялись GitHub Actions и GitHub Pages, разрешения репозитория, домен, HTTPS и доступ по опубликованному адресу. Результат последующего согласованного выпуска указан в истории.
- Firefox, Safari, реальные телефоны и планшеты; проверялись размеры viewport в Chromium.
- Чтение интерфейса реальными NVDA/VoiceOver и полный аудит WCAG. Выполнены базовые проверки клавиатуры, имён и сообщений, а не сертификация доступности.
- Реальная потеря питания, повреждение диска и все браузерные политики хранения. Ошибки API и квоты моделировались, а закрытие/повторный запуск браузера проверено реально.

## Ограничения MVP

- Нет облачной синхронизации, фонового чтения аккаунта HoYoverse и внешней игровой базы. Данные и расписания вводятся вручную; смола приблизительная и зависит от часов устройства.
- Хранение локальное и общее для origin, не папки URL. Очистка сайта/профиля или приватного окна может удалить данные. Регулярно скачивайте JSON вне браузера.
- Импорт — полная замена схемы 1, до 5 МиБ. Для локальной копии нужно дополнительное место. Поддерживается одна последняя копия, а не автоматическая история всех версий; сохраните нужные копии файлами.
- Копия намеренно остаётся после очистки рабочих данных. Для полного удаления используется очистка данных сайта браузером.
- Параллельные изменения вкладок не объединяются. Обнаруженное расхождение блокирует запись/замену; экспортируйте несохранённые изменения и обновите страницу. Во время импорта рекомендуется одна активная вкладка.
- Интерфейс ориентирован на текущий профиль. Импорт/экспорт сохраняет все профили, но отдельного менеджера создания и переключения нескольких профилей в MVP нет.
- Итоги статистики отражают текущие сохранённые выполнения, а не пожизненный журнал повторных закрытий личных задач. Старые агрегаты рутины без точного времени не распределяются по дням.
